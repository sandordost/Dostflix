# Changelog

## 1.0.0 — 2026-09-03

- Native Qt Quick interface for desktop and automatically scaled Gamescope sessions.
- OpenVPN startup/shutdown lifecycle with a process-scoped nftables kill switch.
- User-configured Prowlarr/Torznab search and one-at-a-time TorrServer streaming.
- Embedded libmpv player with safe buffering, subtitles, resume, fullscreen and fill/crop.
- Durable resumable downloads, disk-space protection, metadata and offline library playback.
- TMDB Highlights with Trending, Best of the current year and randomized High Ratings shelves.
- SDL3 controller support, Steam Input-compatible navigation and an on-screen keyboard.
